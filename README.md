# C++ Basics Learning Roadmap

This repository is structured to help you learn C++ step by step and track progress daily.

## Project Structure

- `cpp_basics/main.cpp` — Starter Hello World program with beginner-friendly comments.

## Daily Progress Tracker

### 1) Variables and Data Types
- [ ] Understand primitive types (`int`, `double`, `char`, `bool`)
- [ ] Learn variable declaration and initialization
- [ ] Practice constants with `const`
- [ ] Explore type conversion (implicit and explicit casting)

### 2) Loops and Control Flow
- [ ] Use `if`, `else if`, and `else` statements
- [ ] Practice `switch` statements
- [ ] Write `for` loops
- [ ] Write `while` and `do-while` loops
- [ ] Use `break` and `continue` effectively

### 3) Functions
- [ ] Define and call functions
- [ ] Understand function parameters and return types
- [ ] Learn function overloading
- [ ] Practice passing by value vs passing by reference
- [ ] Explore default arguments

### 4) Pointers
- [ ] Understand memory addresses and pointer basics
- [ ] Use `*` (dereference) and `&` (address-of)
- [ ] Work with pointers and arrays
- [ ] Learn null pointers and pointer safety basics

### 5) Memory Management
- [ ] Learn stack vs heap memory
- [ ] Allocate and free memory using `new` and `delete`
- [ ] Avoid memory leaks and dangling pointers
- [ ] Understand RAII basics and why smart pointers help
- [ ] Practice with `std::unique_ptr` and `std::shared_ptr`

### 6) Data Structures (STL)
- [ ] Use `std::array` and `std::vector`
- [ ] Learn `std::string` operations
- [ ] Practice with `std::map` and `std::unordered_map`
- [ ] Explore `std::set` and `std::unordered_set`
- [ ] Understand `std::stack` and `std::queue`

### 7) Object-Oriented Programming (OOP)
- [ ] Create classes and objects
- [ ] Use access modifiers (`public`, `private`, `protected`)
- [ ] Understand constructors and destructors
- [ ] Practice encapsulation and abstraction
- [ ] Learn inheritance
- [ ] Learn polymorphism (virtual functions)

## Suggested Routine

- [ ] Study one topic section per day
- [ ] Write at least one small practice program daily
- [ ] Commit your progress at the end of each session
